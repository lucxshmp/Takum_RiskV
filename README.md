# Takum_RiskV
Trabalho para disciplina de Arquitetura e Organização de Computadores. A ideia é desenvolver um novo modelo de instrução Single Instruction, Multiple Data de maior precisão, passando da atual IEEE754 para a Takum. Ela, apesar de já desenvolvida e teorizada, nesse trabalho, é traduzida para a arquitetura open source RISC-V.
